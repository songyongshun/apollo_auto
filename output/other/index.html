CodeBuddy Code 安装与使用

CodeBuddy Code是一款 AI 编程助手 CLI 工具，可在终端中提供代码补全、解释、重构等功能。 CentOS 8 仓库自带的 Node.js 版本过低（10.x），无法满足 CodeBuddy Code 的运行要求，因此需要通过 nvm（Node Version Manager） 安装较新版本的 Node.js。

CodeBuddy Code 实战案例

本章通过多个完整案例，展示如何使用 CodeBuddy Code 快速生成可在本地运行的实用程序。 每个案例都包含提示词（Prompt）和生成结果，帮助你体会"一句话生成一个程序"的开发体验。
