CodeBuddy Code 实战案例 —— 体验 AI 编程助手的强大

本章通过多个完整案例，展示如何使用 CodeBuddy Code 快速生成可在本地运行的实用程序。 每个案例都包含提示词（Prompt）和生成结果，帮助你体会"一句话生成一个程序"的开发体验。

📋 前置准备

确保已完成 CodeBuddy CLI 的安装和登录（详见 chapter-03），然后进入工作目录：

mkdir ~/codebuddy_demo
cd ~/codebuddy_demo
codebuddy

💡 提示：以下每个案例，你只需要把提示词复制粘贴给 CodeBuddy，它就会自动为你生成完整的代码文件。

案例一：科学计算器（Python）

🎯 目标

生成一个带有图形界面的科学计算器，支持基本运算和常用数学函数。

💬 提示词

帮我用 Python 的 tkinter 库写一个图形界面科学计算器。
要求：
1. 界面美观，按钮用网格布局
2. 支持加减乘除、括号运算
3. 支持 sin、cos、tan、log、sqrt、幂运算
4. 有历史记录显示区域
5. 支持键盘输入
6. 代码保存为 calculator.py

▶️ 运行方式

python calculator.py

📸 运行效果

运行后将弹出一个窗口计算器，你可以点击按钮或直接用键盘输入算式，按下 = 或回车即可得到结果。

案例二：打字速度测试（Python）

🎯 目标

生成一个打字速度测试程序，实时统计 WPM（每分钟字数）和准确率。

💬 提示词

帮我写一个 Python 打字速度测试程序，要求：
1. 使用 curses 库实现终端界面
2. 随机显示一段英文句子让用户打字
3. 实时显示：当前速度（WPM）、准确率、剩余时间
4. 用不同颜色高亮显示：已正确输入的部分（绿色）、错误部分（红色）、当前光标位置
5. 测试时间 60 秒，结束后显示最终成绩和评级
6. 支持多轮测试，按任意键开始下一轮
7. 代码保存为 typing_test.py

▶️ 运行方式

python typing_test.py

📸 运行效果

终端中会显示一段随机英文文本，你输入的内容会实时用颜色标注对错，顶部显示实时速度和准确率。

案例三：2048 数字游戏（Python）

🎯 目标

生成经典的 2048 数字合并游戏，支持方向键操作。

💬 提示词

帮我用 Python 写一个 2048 游戏，要求：
1. 4x4 的网格，用字符界面显示（可以用彩色数字）
2. 支持上下左右方向键操作
3. 每次滑动后随机在空格生成 2 或 4
4. 相同数字碰撞时合并并计分
5. 实时显示当前分数和最高分
6. 游戏结束时显示 Game Over 和最终得分
7. 支持重新开始（按 R 键）
8. 数字用不同颜色区分（2是白色，4是浅黄，8是橙色，16以上是红色）
9. 代码保存为 game_2048.py

▶️ 运行方式

python game_2048.py

📸 运行效果

终端中显示 4×4 彩色方格，使用方向键滑动数字，相同数字会合并，努力合成 2048 吧！

案例四：俄罗斯方块（Python）

🎯 目标

生成经典俄罗斯方块游戏，支持方块旋转、计分和等级系统。

💬 提示词

帮我用 Python 的 curses 库写一个俄罗斯方块游戏，要求：
1. 标准 10x20 的游戏区域
2. 7 种标准方块（I、O、T、S、Z、J、L），每种用不同颜色
3. 支持操作：左移、右移、软降（加速下落）、硬降（直接落底）、旋转
4. 消行计分：1行100分，2行300分，3行500分，4行800分
5. 每消10行升级一级，下落速度加快
6. 右侧显示：下一个方块预览、当前分数、当前等级、已消行数
7. 游戏结束显示最终成绩
8. 代码保存为 tetris.py

▶️ 运行方式

python tetris.py

📸 运行效果

终端中呈现经典的俄罗斯方块界面，右侧有信息面板，使用方向键和空格键操控方块。

案例五：贪吃蛇（Python）

🎯 目标

生成一个终端版贪吃蛇游戏，画面流畅，操作灵敏。

💬 提示词

1. 20x40 的游戏区域，用字符绘制边界
2. 蛇身用 █ 字符，蛇头用不同颜色标识

python snake.py

终端中出现一条不断移动的蛇，吃掉食物后变长，速度逐渐加快，考验你的反应速度！

终端中显示井字棋棋盘，你和 AI 轮流对弈。AI 采用了最优策略，你能逼平它吗？

案例七：个人记账本（Python）

🎯 目标

生成一个基于终端的个人记账程序，支持数据持久化存储。

💬 提示词

帮我写一个 Python 终端个人记账本程序，要求：
1. 数据保存到 CSV 文件（ledger.csv）
2. 功能菜单：添加记录、查看所有记录、按日期筛选、按类别筛选、收支统计、删除记录
3. 每条记录包含：日期、类型（收入/支出）、类别（餐饮/交通/娱乐/工资/其他）、金额、备注
4. 支持统计功能：本月总收入、总支出、结余，按类别汇总
5. 界面用表格形式展示数据，对齐美观
6. 支持导出为文本报表
7. 输入验证：金额必须是数字，日期格式为 YYYY-MM-DD
8. 代码保存为 ledger.py

▶️ 运行方式

python ledger.py

📸 运行效果

运行后进入菜单界面，你可以添加收支记录、查看统计报表，所有数据自动保存到 CSV 文件中，下次打开数据还在。

案例八：像素画板（Python）

🎯 目标

生成一个基于终端的像素画绘制工具。

💬 提示词

帮我用 Python 写一个终端像素画板程序，要求：
1. 20x20 的画布，用方块字符显示
2. 8 种颜色可选（用数字 1-8 选择颜色）
3. 操作方式：方向键移动光标，数字键选择颜色，空格键填色，B 键擦除

7. 底部显示操作提示栏
8. 代码保存为 pixel_art.py

▶️ 运行方式

python pixel_art.py

📸 运行效果

终端中出现一个彩色画布，你可以用方向键移动光标，选择不同颜色进行绘制，创作属于你的像素艺术。

通过以上案例，你应该已经体会到 CodeBuddy Code 的强大之处：

🚀 进阶挑战

尝试用以下提示词让 CodeBuddy 帮你生成更复杂的程序：

  1. 五子棋对战：帮我写一个支持双人对战的五子棋游戏，用 Python 实现，有悔棋功能
  2. Markdown 编辑器：帮我用 Python 写一个实时预览的 Markdown 编辑器，左边编辑右边预览
  3. 文件批量重命名工具：帮我写一个文件批量重命名工具，支持正则替换、添加序号、修改扩展名
  4. 天气查询应用：帮我写一个终端天气查询程序，输入城市名显示未来3天天气预报

💡 记住：CodeBuddy Code 是你的编程助手，而不是替代你思考的工具。 理解代码的逻辑比生成代码本身更重要。建议在 CodeBuddy 生成代码后，花时间阅读和理解每一部分！
