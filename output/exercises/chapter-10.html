Linux 网络配置和管理 - 上手操作练习题 (共18题)

基于 Chapter 10（Linux网络配置和管理）知识点设计，所有题目均可在实际Linux系统上操作验证

🎯 真实场景背景

你是一家创业公司的运维实习生。今天公司刚搬进新的办公场地，IT经理给了你一台新安装的Linux服务器，要求你完成网络配置和连通性测试工作。这台服务器需要接入公司内网（192.168.1.0/24），并能正常访问外网和提供Web服务。

从查看网络接口、配置IP地址，到测试网络连通性和排障——这次任务将用到本章学习的所有网络管理知识。

✅ 练习说明

  • 请按要求依次完成各练习。完成后在学习通内打开问卷填写并提交。
  • 本次练习需要联网，请先参考文档完成网络配置。
  • 可以使用普通用户账号执行大部分操作，需要管理员权限时使用sudo。
  • 注意观察每个命令的输出结果，不要只执行命令不看输出。

📋 基础操作篇 (第1-9题)

第1题

题目: 使用 ip addr show（或简写 ip a）查看系统中所有网络接口的信息，记录下有几个网络接口以及它们的名称（如 lo、eth0、ens33 等）。

第2题

题目: 使用 ip route show 查看当前系统的路由表信息，记录下默认网关的IP地址（default via 那一行）。

第3题

题目: 使用 ping -c 4 127.0.0.1 测试本机环回接口的连通性，记录下最小、平均和最大延迟时间。

第4题

题目: 使用 cat /etc/resolv.conf 查看系统的DNS配置，记录下当前配置的 nameserver IP地址。

第5题

题目: 使用 ss -tuln 查看系统当前所有的TCP和UDP监听端口，记录下处于LISTEN状态的TCP端口号有哪些。

第6题

题目: 使用 hostname 查看当前系统的主机名，然后使用 hostnamectl 查看更详细的主机信息，记录下 Static hostname 和 Machine ID。

第7题

题目: 使用 ping -c 4 8.8.8.8 测试到外网IP的连通性，观察输出结果中是否有 100% packet loss，并记录发送和接收的数据包数量。

第8题

题目: 使用 ip link show 查看所有网络接口的MAC地址和状态（UP/DOWN），记录下第一个非环回接口的MAC地址和当前状态。

第9题

题目: 使用 ping -c 4 $(hostname -I | awk '{print $1}') 测试本机IP地址的连通性（也可直接ping本机IP），观察并使用 ss -tuln | grep -c LISTEN 统计正在监听的服务数量。

🚀 进阶操作篇 (第10-15题)

第10题

题目: 使用 ip addr show 查看网络接口的详细信息，找到第一个非环回接口（如 eth0 或 ens33）的IP地址和子网掩码前缀（如 /24），记录下接口名、IP地址和子网前缀长度。

第11题

题目: 使用 route -n 查看路由表（传统方式），与 ip route show 的输出进行对比，记录下两种命令输出中的网关（Gateway）列和Flags列有哪些异同。

第12题

题目: 使用 traceroute 或 mtr 命令追踪到 baidu.com 的路由路径（如系统未安装则使用 ping -R），记录下经过的第1跳路由器的IP地址。

第13题

题目: 使用 ip -s link show <接口名> 查看指定网络接口的收发数据包统计（TX/RX），记录下发送和接收的数据包数量以及错误包（errors）数量。

第14题

题目: 使用 systemctl status NetworkManager 查看网络管理服务的运行状态，观察服务是否处于 active (running)，并记录下服务的主进程PID。

第15题

题目: 使用 ss -tuln | grep LISTEN 结合 wc -l 统计当前系统有多少个TCP端口处于监听状态，再用 ss -tuln 检查是否有常见的Web服务端口（如80、443）处于监听状态。

🏆 挑战操作篇 (第16-18题)

第16题

题目: 模拟网络故障排查——使用本章所学的网络命令组合完成以下诊断流程：

  1. 使用 ip addr show 检查网卡是否处于UP状态
  2. 使用 ping -c 4 网关IP 测试到网关的连通性
  3. 使用 ping -c 4 8.8.8.8 测试到外网的连通性
  4. 使用 cat /etc/resolv.conf 检查DNS配置是否正确
  5. 使用 ss -tuln 检查目标端口是否在监听 根据以上各步骤的输出，判断如果网络不通最可能出在哪一环。

第17题

题目: 写一条组合命令（使用管道和命令替换），一次性输出以下网络状态报告：

==== 网络状态报告 ====
主机名:      [hostname的输出]
IP地址:      [ip addr show中的IP]
默认网关:    [ip route show中的网关]
DNS服务器:   [/etc/resolv.conf中的nameserver]
监听端口数:  [ss -tuln中LISTEN的端口数]
连接状态:    [ping 8.8.8.8的连通性结果]
===========================

第18题

题目: 模拟完整的网络部署与验证流程——假设你需要在服务器上配置网络并验证服务可用性，按顺序完成以下操作，将所有输出结果重定向到 network_setup_report.txt 文件中：

  1. 使用 ip addr show 查看当前网络接口信息
  2. 使用 ip route show 查看路由表
  3. 使用 ping -c 4 网关IP 测试网关连通性
  4. 使用 ping -c 4 8.8.8.8 测试外网连通性
  5. 使用 cat /etc/resolv.conf 查看DNS配置
  6. 使用 hostnamectl 查看完整的主机信息
  7. 使用 ss -tuln 查看所有监听端口
